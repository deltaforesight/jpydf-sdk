# Security policy

## Report a vulnerability privately

Use [GitHub Private Vulnerability Reporting](https://github.com/deltaforesight/jpydf-sdk/security/advisories/new)
for suspected vulnerabilities in the JPYdf SDK or JPY DeFi-specific code. A GitHub
account is required. Reports are shared privately with the repository's security
maintainers.

Include the affected version or commit, affected component, reproduction steps,
and potential impact. Use a minimal proof of concept that does not put user funds
or data at risk. Never include private keys, seed phrases, access tokens, or
other credentials. Keep vulnerability details out of public issues and general
support channels.

The SDK is a test-only alpha. Review focuses on the current source; there is no
stable production SDK release or maintenance commitment for older alpha versions.
This reporting channel does not establish a bug bounty or promise a reward.

## Non-security support

Use [SDK issues](https://github.com/deltaforesight/jpydf-sdk/issues) for integration
questions and non-sensitive bugs.
